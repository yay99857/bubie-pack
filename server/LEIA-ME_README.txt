Bubie Pack - Server Pack
Minecraft 1.21.1 / NeoForge 21.1.265 / Java 21

PORTUGUÊS
1. Instale o Java 21.
2. Rode start.sh (Linux/macOS) ou start.bat (Windows).
   Na primeira vez, o script baixa e instala o NeoForge 21.1.265.
3. O servidor para e cria o eula.txt. Leia a EULA do Minecraft
   (https://aka.ms/MinecraftEULA), troque para eula=true e rode o script de novo.
4. Memória: edite user_jvm_args.txt (padrão 8 GB).
5. Chat de voz (Simple Voice Chat): libere a porta UDP 24454.
6. Pré-gere o mapa antes de abrir: /chunky radius 3000 e depois /chunky start

Este pacote não tem os mods que só rodam no cliente (Sodium, Iris,
ImmediatelyFast, Entity Culling, Controlling, Searchables, Mouse Tweaks,
Extreme Sound Muffler, Better Advanced Tooltips, Enchantment Descriptions).
Os jogadores usam o pack normal pelo CurseForge App.

ENGLISH
1. Install Java 21.
2. Run start.sh (Linux/macOS) or start.bat (Windows).
   The first run downloads and installs NeoForge 21.1.265.
3. The server stops and creates eula.txt. Read the Minecraft EULA
   (https://aka.ms/MinecraftEULA), set eula=true and run the script again.
4. Memory: edit user_jvm_args.txt (default 8 GB).
5. Voice chat (Simple Voice Chat): open UDP port 24454.
6. Pre-generate the map before opening: /chunky radius 3000 then /chunky start

Client-only mods are not included (Sodium, Iris, ImmediatelyFast, Entity
Culling, Controlling, Searchables, Mouse Tweaks, Extreme Sound Muffler,
Better Advanced Tooltips, Enchantment Descriptions).
Players use the regular pack from the CurseForge App.
